# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a Vulnerability

Please open a private security advisory on GitHub or email the maintainer listed in `package.json`.

Do not file public issues for unpatched XSS / content injection risks in email HTML rendering.

We aim to acknowledge reports within 7 days.
